# Lernkarten und Alltagswortschatz

Redaktioneller Anfangsbestand vom 17.10.2026. Keine offiziellen Prüfungsfragen; fachliche Freigabe steht aus. Persönliche Änderungen werden getrennt gespeichert.

## Mathematik

| Frage | Antwort |
|---|---|
| Was ist eine Summe? | Das Ergebnis einer Addition, zum Beispiel 3 + 4 = 7. |
| Was ist eine Differenz? | Das Ergebnis einer Subtraktion, zum Beispiel 9 − 2 = 7. |
| Was ist ein Produkt? | Das Ergebnis einer Multiplikation, zum Beispiel 3 × 4 = 12. |
| Was ist ein Quotient? | Das Ergebnis einer Division, zum Beispiel 12 ÷ 3 = 4. |
| Was ist eine Primzahl? | Eine natürliche Zahl größer als 1, die genau zwei positive Teiler hat: 1 und sich selbst. |
| Was bedeuten Zähler und Nenner? | Beim Bruch steht der Zähler oben und der Nenner unten. Der Nenner nennt die Anzahl gleich großer Teile. |
| Was bedeutet Prozent? | Prozent heißt „von hundert“. 25 % sind 25 von 100, also ein Viertel. |
| Was ist der Grundwert? | Das Ganze, auf das sich eine Prozentangabe bezieht. Der Grundwert entspricht 100 %. |
| Was ist eine Variable? | Ein Zeichen für eine Zahl, etwa x. Ihr Wert kann unbekannt sein oder sich ändern. |
| Was ist eine Gleichung? | Eine Aussage, dass zwei Terme gleich sind. Eine Lösung macht diese Aussage wahr. |
| Was ist der Umfang? | Die Länge des Randes einer ebenen Figur. Beim Rechteck werden alle vier Seiten addiert. |
| Was ist der Flächeninhalt? | Die Größe einer Fläche. Er wird zum Beispiel in cm² oder m² angegeben. |
| Was ist das Volumen? | Der Rauminhalt eines Körpers, zum Beispiel in cm³, m³ oder Litern. |
| Was ist der Mittelwert? | Die Summe aller Werte geteilt durch die Anzahl der Werte. |
| Was ist der Median? | Der mittlere Wert einer geordneten Liste. Bei gerader Anzahl ist es der Mittelwert der beiden mittleren Werte. |

## Deutsch

| Frage | Antwort |
|---|---|
| Was ist ein Nomen? | Ein Wort für Menschen, Tiere, Dinge oder Vorstellungen. Nomen werden großgeschrieben, zum Beispiel „Hoffnung“. |
| Was ist ein Verb? | Ein Wort, das eine Tätigkeit, einen Vorgang oder einen Zustand ausdrückt, etwa „laufen“ oder „sein“. |
| Was ist ein Adjektiv? | Ein Wort, das Eigenschaften beschreibt, zum Beispiel „ruhig“ oder „groß“. |
| Was ist ein Pronomen? | Ein Wort, das etwa ein Nomen ersetzt oder begleitet, zum Beispiel „ich“, „sie“ oder „mein“. |
| Was ist das Subjekt? | Das Satzglied, nach dem du mit „Wer oder was?“ fragst: „Die Katze schläft.“ – die Katze. |
| Was ist das Prädikat? | Das Verb oder die zusammengehörenden Verbteile im Satz: „Sie hat gelesen.“ – hat gelesen. |
| Was ist ein Akkusativobjekt? | Eine Ergänzung, nach der du mit „Wen oder was?“ fragst: „Ich sehe den Bus.“ – den Bus. |
| Was ist ein Dativobjekt? | Eine Ergänzung, nach der du mit „Wem?“ fragst: „Ich helfe dem Freund.“ – dem Freund. |
| Was ist das Präteritum? | Eine Zeitform der Vergangenheit, zum Beispiel „ich ging“ oder „ich lernte“. |
| Was ist das Perfekt? | Eine Vergangenheitsform mit „haben“ oder „sein“ und einem Partizip: „Ich habe gelernt.“ |
| Was ist ein sachlicher Bericht? | Ein Text, der möglichst genau informiert, was wann, wo und mit wem geschehen ist. |
| Was ist eine Inhaltsangabe? | Eine kurze sachliche Wiedergabe des Wesentlichen eines Textes, meist im Präsens. |
| Was ist ein Argument? | Eine begründende Aussage, die eine Behauptung oder einen Standpunkt stützt. |
| Was ist ein direktes Zitat? | Wörtlich übernommener Text, der als Übernahme gekennzeichnet und mit seiner Quelle angegeben wird. |
| Was ist eine Metapher? | Ein bildlicher Ausdruck mit übertragener Bedeutung, zum Beispiel „ein Meer von Blumen“. |

## Sozialkunde

| Frage | Antwort |
|---|---|
| Was bedeutet Demokratie? | Politische Macht geht vom Volk aus und wird unter anderem durch freie Wahlen und Beteiligung legitimiert. |
| Was sind Grundrechte? | Grundlegende Rechte, die Menschen vor ungerechtfertigten Eingriffen des Staates schützen. |
| Was ist das Grundgesetz? | Die Verfassung Deutschlands. Sie regelt Grundrechte und die grundlegende Ordnung des Staates. |
| Was bedeutet Gewaltenteilung? | Staatliche Macht verteilt sich auf Gesetzgebung, ausführende Gewalt und Rechtsprechung. |
| Was ist ein Rechtsstaat? | Ein Staat, in dem staatliches Handeln an Recht und Gesetz gebunden und gerichtlich überprüfbar ist. |
| Was ist Föderalismus? | Die Verteilung staatlicher Aufgaben zwischen Bund und Ländern. |
| Was ist der Bundestag? | Das vom Volk gewählte Parlament auf Bundesebene. Er beschließt unter anderem Gesetze und kontrolliert die Regierung. |
| Was ist der Bundesrat? | Das Organ, durch das die Länder an der Gesetzgebung und Verwaltung des Bundes mitwirken. |
| Was ist eine Kommune? | Eine Gemeinde oder Stadt als örtliche Ebene der Politik und Verwaltung. |
| Was ist eine Koalition? | Ein Bündnis mehrerer Parteien, oft zur gemeinsamen Regierungsbildung. |
| Was ist die Opposition? | Die parlamentarischen Kräfte, die nicht die Regierung tragen und Alternativen sowie Kritik vertreten. |
| Was ist ein Kompromiss? | Eine ausgehandelte Lösung, bei der Beteiligte einen Teil ihrer Forderungen zurücknehmen. |
| Was ist Diskriminierung? | Die Benachteiligung von Menschen wegen zugeschriebener oder tatsächlicher Zugehörigkeiten oder Merkmale. |
| Was ist Solidarität? | Sich für andere und gemeinsame Anliegen einsetzen, besonders wenn jemand Unterstützung braucht. |
| Was ist eine Petition? | Eine Bitte oder Beschwerde an eine zuständige staatliche Stelle oder Volksvertretung. |

## Biologie

| Frage | Antwort |
|---|---|
| Was ist eine Zelle? | Die kleinste lebende Baueinheit eines Organismus. |
| Was ist ein Organ? | Ein Körperteil aus verschiedenen Geweben mit bestimmten Aufgaben, zum Beispiel das Herz. |
| Was ist Fotosynthese? | Grüne Pflanzen bauen mithilfe von Licht aus Wasser und Kohlenstoffdioxid energiereiche Stoffe auf; dabei entsteht Sauerstoff. |
| Was ist Zellatmung? | Der Abbau energiereicher Stoffe zur Freisetzung nutzbarer Energie. Bei aerober Zellatmung wird Sauerstoff benötigt. |
| Was ist Bestäubung? | Die Übertragung von Pollen auf die Narbe einer Blüte derselben Pflanzenart. |
| Was ist Befruchtung? | Die Verschmelzung einer männlichen und einer weiblichen Geschlechtszelle. |
| Was ist ein Ökosystem? | Ein Ökosystem besteht aus Lebewesen und ihrer unbelebten Umwelt, die miteinander in Wechselwirkung stehen. |
| Was ist ein Biotop? | Der Lebensraum mit seinen unbelebten Bedingungen, zum Beispiel Boden, Wasser, Licht und Temperatur. |
| Was ist eine Population? | Individuen derselben Art, die zu einer bestimmten Zeit in einem Gebiet leben. |
| Was ist ein abiotischer Umweltfaktor? | Ein Einfluss der unbelebten Umwelt, zum Beispiel Licht, Temperatur oder Wasser. |
| Was ist ein Produzent im Ökosystem? | Ein Lebewesen, das organische Stoffe aus anorganischen Stoffen aufbaut, zum Beispiel eine grüne Pflanze durch Fotosynthese. |
| Was ist ein Konsument? | Ein Lebewesen, das organische Stoffe mit der Nahrung aufnimmt, zum Beispiel ein Pflanzenfresser. |
| Was ist ein Zersetzer? | Ein Organismus, der abgestorbenes organisches Material abbaut, etwa viele Pilze oder Bakterien. |
| Was ist ein Reflex? | Eine schnelle, unwillkürliche Reaktion auf einen bestimmten Reiz. |
| Was ist eine Hypothese? | Eine begründete, überprüfbare Vermutung über einen Zusammenhang. |

## Geografie

| Frage | Antwort |
|---|---|
| Was zeigt ein Kartenmaßstab? | Das Verhältnis zwischen einer Strecke auf der Karte und der entsprechenden Strecke in Wirklichkeit. |
| Was ist eine Kartenlegende? | Eine Erklärung der auf einer Karte verwendeten Zeichen und Farben. |
| Was ist der Äquator? | Der gedachte Breitenkreis bei 0°, der die Erde in Nord- und Südhalbkugel teilt. |
| Was ist geografische Breite? | Der Winkelabstand eines Ortes vom Äquator nach Norden oder Süden. |
| Was beschreibt das Wetter? | Den Zustand der Atmosphäre an einem Ort zu einer bestimmten Zeit, etwa Temperatur, Wind und Niederschlag. |
| Was beschreibt das Klima? | Die typischen Wetterverhältnisse und ihre Schwankungen in einer Region über einen langen Zeitraum. |
| Was ist Verdunstung? | Der Übergang von flüssigem Wasser zu Wasserdampf. |
| Was ist Kondensation? | Der Übergang von Wasserdampf zu flüssigem Wasser, zum Beispiel zu kleinen Wolkentröpfchen. |
| Was ist Erosion? | Der Abtrag von Boden oder Gestein, etwa durch fließendes Wasser oder Wind. |
| Was ist eine Ressource? | Ein nutzbares Mittel oder ein natürlicher Vorrat, zum Beispiel Wasser, Boden oder Rohstoffe. |
| Was ist ein erneuerbarer Energieträger? | Eine sich erneuernde Energiequelle, zum Beispiel Wind oder Sonnenstrahlung. |
| Was ist ein Standortfaktor? | Eine Bedingung, die die Wahl eines Standorts beeinflusst, etwa Verkehrsanbindung oder verfügbare Arbeitskräfte. |
| Was ist Infrastruktur? | Grundlegende Einrichtungen und Netze, zum Beispiel Straßen, Wasserleitungen, Schulen und Internetverbindungen. |
| Was ist Globalisierung? | Die zunehmende weltweite Verflechtung, etwa durch Handel, Produktion, Kommunikation und Verkehr. |
| Was sind räumliche Disparitäten? | Unterschiede zwischen Regionen, zum Beispiel bei Einkommen, Versorgung oder Bildungsmöglichkeiten. |

## Alltagswortschatz

| Wort | Bedeutung | Falsche Auswahlantworten |
|---|---|---|
| Universität | Eine Hochschule, an der Menschen studieren und forschen. | Eine Arztpraxis für Tiere. / Ein Geschäft für Lebensmittel. |
| Termin | Ein vereinbarter Zeitpunkt für ein Treffen oder eine Aufgabe. | Ein Ort zum Übernachten. / Ein Gegenstand zum Messen. |
| Frist | Ein Zeitraum oder Endtermin, bis zu dem etwas erledigt sein muss. | Eine beliebige Pause ohne Ende. / Eine kurze Wegbeschreibung. |
| Antrag | Eine Bitte an eine zuständige Stelle, über etwas zu entscheiden. | Ein Bericht über das gestrige Wetter. / Ein Werkzeug zum Schrauben. |
| Bescheinigung | Ein schriftlicher Nachweis über einen bestimmten Sachverhalt. | Ein Versprechen ohne jede Angabe. / Ein Behälter für Werkzeuge. |
| Voraussetzung | Etwas, das erfüllt sein muss, damit etwas anderes möglich ist. | Das zufällige Ende einer Geschichte. / Eine Einladung zum Essen. |
| zuständig | Für eine bestimmte Aufgabe verantwortlich. | Gerade sehr müde. / Besonders weit entfernt. |
| zuverlässig | So, dass man sich auf die Person oder Sache verlassen kann. | Immer unvorhersehbar und unpünktlich. / Nur für einen einzigen Tag geöffnet. |
| verschieben | Einen Termin auf einen anderen Zeitpunkt legen oder etwas an eine andere Stelle bewegen. | Etwas endgültig beweisen. / Eine Rechnung immer halbieren. |
| vereinbaren | Sich gemeinsam auf etwas einigen. | Etwas heimlich verschwinden lassen. / Eine Sache ohne Grund zerbrechen. |
| Unterlagen | Dokumente, die für eine Aufgabe oder einen Vorgang gebraucht werden. | Nur die Füße eines Tisches. / Ausschließlich kurze Musikstücke. |
| Gebühr | Ein Geldbetrag, der für eine bestimmte Leistung verlangt wird. | Ein kostenloses Geschenk. / Die Länge einer Strecke. |
| Quittung | Ein Beleg, der bestätigt, dass eine Zahlung empfangen wurde. | Ein Fahrplan ohne Uhrzeiten. / Ein Hinweis auf die nächste Haltestelle. |
| Umtausch | Eine Ware zurückgeben und dafür eine andere erhalten. | Eine Ware ohne Veränderung behalten. / Einen Raum gründlich reinigen. |
| Rücksicht | Die Bedürfnisse und Gefühle anderer mitbedenken. | Nur die eigenen Wünsche beachten. / Immer rückwärts gehen. |
| vereinfachen | Etwas leichter verständlich oder leichter ausführbar machen. | Etwas absichtlich komplizierter machen. / Etwas mit Sicherheit verdoppeln. |
| ergänzen | Etwas Fehlendes hinzufügen. | Alles Vorhandene entfernen. / Eine Aussage ohne Prüfung ablehnen. |
| begründen | Sagen, warum eine Aussage oder Entscheidung sinnvoll ist. | Eine Behauptung nur lauter wiederholen. / Einen Text ohne Erklärung löschen. |
| vergleichen | Gemeinsamkeiten und Unterschiede untersuchen. | Zwei Dinge grundsätzlich gleich nennen. / Etwas ohne Hinsehen auswählen. |
| vermutlich | Wahrscheinlich, aber noch nicht sicher. | Mit vollständiger Sicherheit. / Unter keinen Umständen möglich. |
| verbindlich | So zugesagt oder festgelegt, dass man sich daran halten soll. | Völlig beliebig und ohne Zusage. / Nur in einer Fantasiegeschichte vorhanden. |
| freiwillig | Aus eigener Entscheidung, ohne dazu gezwungen zu werden. | Nur unter Zwang. / Ganz ohne eigenes Wissen. |
| geeignet | Für einen bestimmten Zweck passend. | Für jeden Zweck grundsätzlich unbrauchbar. / Immer besonders teuer. |
| Gelegenheit | Eine passende Möglichkeit oder ein günstiger Zeitpunkt. | Ein fest verschlossener Gegenstand. / Ein Fehler in jeder Rechnung. |
| Missverständnis | Eine Situation, in der etwas anders verstanden wird, als es gemeint war. | Eine von allen gleich verstandene Aussage. / Eine absichtlich leere Schublade. |
